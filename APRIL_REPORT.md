# April report — Test design & data-driven coverage

## Что добавлено
- Таблица тест-дизайна для `GET /posts?userId=` (эквивалентные классы + граничные значения).
- Data-driven автотест, параметризованный кейсами APR-01..APR-08.
- Проверки:

  - тип данных (list)
  - при наличии элементов: контракт post (ключи/типы)

В апреле добавлено покрытие query-параметров фильтрации с граничными значениями и эквивалентными классами.
